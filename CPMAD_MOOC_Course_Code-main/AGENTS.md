# Local course collection

Keep work inside this course folder. Preserve existing user files and leave unrelated projects alone. Keep all work local, with no Git initialization, commits, uploads, or publishing unless the user authorizes a separate submission task.

Use the Udemy curriculum as the source for lecture order and attribution. Record what evidence was available and label independent implementations and local files with unverified provenance accordingly. Store Firebase app settings in ignored local configuration files.

For project changes, resolve dependencies, format Dart files, run the analyzer and the project's automated checks, and update the test report with actual results.
