# Dart Basics Project
A console-based Dart project demonstrating the core syntax, constructs, and paradigms of Dart 3.

## Topics Covered
1. **01_variables_and_types.dart**: Numbers (`int`, `double`), Strings, Booleans, `var`, `final`, and `const`.
2. **02_functions_and_control_flow.dart**: Named and positional parameters, default values, arrow syntax, `if-else`, `switch-case`, loops.
3. **03_collections_and_null_safety.dart**: `List`, `Set`, `Map`, collection operators (`...`, `collection if`), null safety operators (`?`, `!`, `??`, `??=`).
4. **04_oop_classes_and_inheritance.dart**: Classes, constructors (named, redirecting, const), inheritance, abstract classes, interfaces, and mixins.
